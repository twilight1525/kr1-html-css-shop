В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.
## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Проект реализован как многостраничный сайт интернет-магазина.

### Страницы проекта

- `index.html` — главная страница (hero, преимущества, популярные товары);
- `catalog.html` — каталог с сеткой карточек и фильтрами;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — страница оформления заявки;
- `contacts.html` — контакты и переход к заявке.

### Технологии

- HTML5, семантическая разметка;
- CSS3: переменные, Flexbox, CSS Grid, состояния `:hover`/`:focus-visible`;
- JavaScript: модальное окно `<dialog>`, валидация формы, кнопка «Наверх»;
- БЭМ-именование классов;
- Позиционирование: `relative`, `absolute`, `fixed`, `sticky`;
- Git + GitHub Pages.

### Самостоятельные доработки

- 6 товаров в каталоге вместо 3;
- бейджи «Новинка», «Скидка», «Хит» на карточках;
- хлебные крошки на странице товара;
- фильтры каталога со `sticky`-позиционированием;
- кнопка «Наверх» с `position: fixed`;
- таблица характеристик товара;
- страница контактов.
